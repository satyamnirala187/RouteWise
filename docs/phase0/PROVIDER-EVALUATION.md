## Google Routes: documented facts relevant to RouteWise

| Topic | Finding (official docs, read 2026-10-12) |
|---|---|
| Two-wheeler coverage | `TWO_WHEELER` is for motorized two-wheelers, not bicycles. **India is on the supported list** (40 countries, page updated 2026-10-08). The mode is **beta**: routes "might not always include optimal paths for motorcycles", and apps must display a beta warning for two-wheel routes they show. |
| Matrix limits | ≤ 625 elements (origins × destinations) per request; ≤ 100 with `TRAFFIC_AWARE_OPTIMAL`; ≤ 50 place-ID/address waypoints; 3,000 elements per minute rate limit. |
| Response handling | The field mask must include `status`, or every element appears OK. Elements carry `condition` `ROUTE_EXISTS` / `ROUTE_NOT_FOUND`. proto3 JSON omits zero values, which the adapter handles. |
| Billing | Billed per element returned. `TWO_WHEELER` triggers the **Enterprise** SKU; traffic-aware triggers **Pro**. |
| Prices (USD, global list, updated 2026-10-08) | Essentials: 10,000 free/month, then $5.00 per 1,000. Pro: 5,000 free, then $10.00. **Enterprise: 1,000 free, then $15.00 per 1,000** (cheaper tiers above 100k: $12, $9, $4.50, $1.14). |
| Display | "Routes API results displayed on a map must be shown on a Google Map." **Showing Google route results on Leaflet/OSM tiles is not permitted** by this policy. |
| Caching | Most Routes content may not be cached; place IDs may be stored. Exact allowed durations are in the Maps service terms, which were not reviewed. **Storing a matrix offline or for reuse is not established as permitted.** |

## Projected volume and cost

Generated by `python -m routewise_spike cost-projection` ([evidence](../../spikes/routing/evidence/cost_projection.md)).

Assumptions: 26 rounds per month; 2 reroutes per rider per round. Locations = orders + 2 starts + 1 distinct fixed end per rider, an upper bound. Elements = origins × destinations, with the full matrix requested again for each reroute.

| Orders / riders | Elements per initial matrix (requests) | Per round | Monthly elements | Enterprise (TWO_WHEELER) | Essentials (DRIVE) |
|---|---|---|---|---|---|
| 20 / 3 | 625 (1) | 841 | 21,866 | **$312.99/month** | $59.33/month |
| 50 / 5 | 3,249 (9) | 3,739 | 97,214 | **$1,443.21/month** | $436.07/month |
| 100 / 8 | 12,100 (25) | 13,396 | 348,296 | **$4,464.55/month** | $1,443.18/month |

Reroutes are cheap compared with the initial square matrix: an origin row alone is 1 × (remaining + 1) elements. The cost is driven by the **initial full matrix**. Reusing the initial matrix for reroutes would save little and is not established as permitted under Google's caching terms.

## Options for D04 (owner decision; nothing selected or activated)

| Option | Two-wheeler fit | Cost shape | Leaflet / offline fit | Risks |
|---|---|---|---|---|
| **A. Google Routes, `TWO_WHEELER`** | Best documented fit; India supported (beta) | Highest (Enterprise SKU, table above) | Results must be shown on a Google Map, so Leaflet is out. Matrix caching restricted, so offline saved lists may hold only our own order data and sequence. | Beta quality; spend grows ~quadratically with orders |
| **B. Google Routes, `DRIVE`** | Car routing for scooters, so may over-estimate detours | ~3–5× cheaper than A | Same display/cache constraints as A | Car-only roads and restrictions differ from two-wheelers |
| **C. Self-hosted OSRM or similar OSM engine with a custom motorcycle profile** | Must be built and validated (the default OSRM `car` profile was tested here) | No per-element fee; pay for a small server and maintenance | ODbL data allows storage and Leaflet display with attribution | Ops burden; profile quality and map freshness are on us |
| **D. Public OSRM demo** | Car only | Free | — | **Not allowed for production** (non-commercial, no SLA). Research evidence only. |

**Recommendation for the owner's review:** pick a target pilot size first. If the pilot is ≤ 20 orders/day, the A-vs-C choice is mainly about the Leaflet display rule and two-wheeler fidelity rather than cost. Then run a **capped** Google `TWO_WHEELER` trial: 6 public points = 36 elements, within the 1,000 free Enterprise elements. Use a key restricted to the Routes API and a budget alert, and compare it against OSRM on the same points before deciding D04. **Proposed spending cap for the trial: US $0, i.e. stay inside the free monthly allowance.** This is a proposal; no billing was enabled.

## How to run the blocked check once approved

```bash
cp .env.example .env            # git-ignored; put the restricted key in GOOGLE_MAPS_API_KEY
set -a; source .env; set +a
cd spikes/routing
.venv/bin/python -m routewise_spike google-check --allow-billing --points 6   # 36 elements
ROUTEWISE_LIVE_TESTS=1 .venv/bin/python -m pytest -q -m live
```

The command stores metadata only (status, latency, element count, whether asymmetry was observed), not Google route content.
