  1. CREATE DATABASE routewise_upgrade_scratch TEMPLATE routewise_phone   (local cluster, superuser from the git-ignored .env)
  2. phone_db.schema_state(scratch), then phone_db.upgrade(scratch, db_name="routewise_upgrade_scratch")

  4. DROP DATABASE routewise_upgrade_scratch; confirm routewise_phone is unchanged

`phone_db.py upgrade` (docs/phase3/PHONE-TEST-GUIDE.md, section A0).
